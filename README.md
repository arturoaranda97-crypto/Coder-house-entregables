# Coder-house-entregables
El presente repositorio es para el curso de Data Analitycs de coder house , en el se estaran realizando el analisis de ventas de productos , clientes ,ventas y categorias.

--Entregable 3
Se realiza a creación de la base de datos para los siguientes scripts , ademas de generar un orden y normalizacion para cuando se tenga que conectar a power bi.

--Entregable 4 
Se manipulan los datos con SUM , AVG , COUNT para el analisis de las tablas, respondiendo preguntas especificas.

--Entregable 5
Se utilizan los Joins para tener una visualización mas grande de los datos y ademas como están conectados y que resultados podemos sacar de los mismos.Observando si tenemos valores nulos y creando columnas para determinar distintos periodos.
